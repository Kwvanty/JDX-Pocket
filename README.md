# JDX Pocket — веб-приложение для iPhone

## Что внутри
- Обзор дня и статистика задач/заметок
- Задачи: добавление, выполнение, удаление и фильтры
- Заметки с локальным сохранением
- Таймер фокуса на 5, 15 или 25 минут
- Смена неонового акцента
- Экспорт резервной копии JSON
- PWA manifest, иконки и service worker для офлайн-работы после первого посещения

## Как запустить на iPhone
1. Распакуй ZIP.
2. Размести **содержимое** папки `jdx_pocket` на статическом хостинге с HTTPS (например, GitHub Pages или Netlify). В корне сайта должны лежать `index.html`, `style.css`, `app.js`, `manifest.json`, `sw.js` и папка `icons`.
3. Открой адрес сайта в Safari на iPhone.
4. Нажми «Поделиться» → «На экран Домой» (в некоторых версиях iOS пункт может называться немного иначе).
5. Оставь включённым «Открывать как веб-приложение», если такой переключатель отображается, и нажми «Добавить».

## Важно
- Файлы готовы, но сами по себе они ещё не размещены в интернете. Чтобы Safari мог установить веб-приложение с иконкой, ему нужен HTTPS-адрес.
- Заметки и задачи хранятся в локальном хранилище браузера на этом устройстве. Очистка данных Safari или открытие в другом браузере может удалить/не перенести их. Используй экспорт для резервной копии.
- Шрифт Inter загружается из Google Fonts, если доступен интернет; при его отсутствии используется системный шрифт.
- Это веб-приложение, не IPA и не замена iOS.
